# Security policy

## Reporting a vulnerability

Email **contact@monerometrics.net** with a description, the affected URL or
component, and steps to reproduce. You can also use GitHub's private
vulnerability reporting on this repository.

Please do not open a public issue for a security problem, and do not run
load tests or denial-of-service tests against the public API or the onion
service.

You will get an answer within 7 days. Fixes are deployed as soon as they are
ready, and credited in the changelog if you wish.

## Scope

- https://monerometrics.net and https://api.monerometrics.net
- the onion mirror
- the code in this repository

The data served is public and read-only: there are no accounts, no API keys
and no personal data to protect beyond the infrastructure itself.
